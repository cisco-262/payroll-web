02 / PRIVACY BY CONTROL

隐私不靠一句承诺，
而靠明确的控制。

把数据位置、管理权限与员工访问路径说清楚，让安全措施可以检查，也可以由企业持续管理。

◈

数据由企业管理

数据库留在企业自建环境。网站示例不采集工资；正式 App 按企业地址连接，不需要集中上传至公共薪资平台。

⌘

连接与身份分层保护

HTTPS 传输，后台密码与 MFA，员工设备绑定、请求签名和令牌轮换；App 使用系统认证保护本地访问。

✓

发布可追溯，访问有边界

角色与部门权限控制、审批记录、更正历史与加密备份。App 切入后台后锁定，不新增工资离线缓存。

自建部署仍需维护系统补丁、证书、备份及网络策略。任何系统都无法承诺零风险；实际安全取决于部署配置与持续运维。

04 / GOOD TO KNOW

在开始之前，
你可能想知道。

社区版等于开源吗？

不等于。私有化社区版描述免费自建的交付模式，不承诺公开全部业务源码。公开部署资料、Excel 字段示例及使用文档，以正式发布的许可和内容为准。

数据一定不会离开内网吗？

数据库存放在企业管理的服务器。若员工从外网查阅，经授权的工资数据会通过 HTTPS 传至其设备；因此我们不宣称全部数据“绝不出内网”。数据库本身无需作为公网服务开放。

如何校验官方交付包？

正式版本可提供 SHA-256 校验值用于检查文件完整性。哈希校验不等于数字签名、安全认证或无漏洞证明；镜像签名及漏洞扫描应分别提供发布记录。

这是在线薪资 SaaS 吗？

采用企业自建服务端与官方 iOS 客户端的模式。企业负责服务端和数据，员工设备直接连接企业 HTTPS 地址。此产品介绍网站不承载企业工资数据库。

会自动计算工资和个税吗？

当前负责导入、审核、发布和查阅工资条，不代替工资、税费、社保或公积金核算与申报。工资数据以企业核定结果为准。

普通员工也要创建后台账号和 MFA 吗？

不需要。员工档案与后台操作账号分开，授权 HR 核验身份并绑定员工手机。后台管理人员使用密码及 MFA，员工在 App 内使用系统认证解锁。

可以在内网用 IP 地址访问吗？

生产环境必须使用 HTTPS。管理员可开启内网 IP HTTPS，自动生成自签名证书；内网电脑和手机须安装并信任该证书。员工 iOS 配对继续使用企业配置的公开 HTTPS 地址。

01

为什么服务端免费？你们如何盈利？

免费自建服务端是企业私有薪资基础设施，不按人头收取服务端年费。商业化来自官方 iOS 客户端的单设备永久访问买断。首次企业绑定成功后可全功能体验两个月；到期未购买时暂停同步新工资，本机已保存历史仍可解锁查阅。

02

免费自建，包含哪些使用权限？

OpsHome Payslip 提供免费私有化自建 / 社区自托管版本。企业可按产品许可部署官方 Docker 镜像，并配合官方 iOS 客户端使用。免费部署不等于获得服务端源码修改或再分发授权。

03

服务器损坏或迁移，员工需要重新配对吗？

恢复包含设备绑定的加密快照，并保留原企业 HTTPS 地址和对应信任配置后，快照内已有设备可继续使用；会话轮换由配套 App 自动签名恢复。快照之后新增的数据、配对或撤销变化不在旧快照中，因此应定期备份并妥善保管口令。

04

Excel 有二三十列，各月表头不同，也能导入吗？

支持全动态表头与实际数据行数。人工指定工号、姓名和实发工资后，其余明细按金额或文本处理，所有金额列独立汇总。跨月分析按相同列名称对齐；同义但不同名称的字段应由企业统一命名。上传资源保护及 Excel 本身的容量限制仍适用。

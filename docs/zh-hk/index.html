02 / PRIVACY BY CONTROL

私隱不靠一句承諾，
而靠明確的控制。

清楚交代資料位置、管理權限與員工存取路徑，讓安全措施可以檢查，也可以由企業持續管理。

◈

資料由企業管理

資料庫留在企業自建環境。網站示例不收集工資；正式 App 按企業位址連線，毋須集中上傳至公共薪資平台。

⌘

連線與身份分層保護

HTTPS 傳輸，後台密碼與 MFA，員工裝置綁定、請求簽署及權杖輪換；App 以系統認證保護本機存取。

✓

發佈可追溯，存取有邊界

角色及部門權限控制、審批紀錄、更正歷史與加密備份。App 進入背景後鎖定，不新增工資離線快取。

自建部署仍須維護系統修補、憑證、備份及網絡政策。任何系統都無法承諾零風險；實際安全取決於部署設定與持續維運。

發佈及查閱糧單

匯入、預覽、審核、發佈。員工透過已綁定的 iOS 客戶端查閱。

展開部署與連線清單
  1. 選擇企業自有設備或企業管理的伺服器，準備 Docker、持久儲存及備份位置。
  2. 設定員工可存取的 HTTPS 位址及可信代理；正式後台禁止直接使用內網 HTTP 登入。
  3. 使用正式交付映像、Compose 設定及部署文件；毋須取得完整業務原始碼。升級保留原資料卷、帳戶及 MFA。
  4. 首次由系統管理員設定企業與後台角色；授權 HR 建立員工檔案，核實身份後綁定。
  5. 如需內網 IP HTTPS，可由管理員在後台啟用自簽憑證，並向內網終端分發信任。

官方映像倉庫及公開部署資料尚待正式發佈。本頁介紹交付模式，不提供未經確認的拉取命令；私有化社區版不代表開源授權。

04 / GOOD TO KNOW

開始之前，
你可能想知道。

社區版等於開源嗎？

不等於。私有化社區版描述免費自建的交付模式，不承諾公開全部業務原始碼。公開部署資料、Excel 欄位示例及使用文件，以正式發佈的授權及內容為準。

資料一定不會離開內網嗎？

資料庫儲存於企業管理的伺服器。員工從外網查閱時，獲授權的工資資料會透過 HTTPS 傳至其裝置，因此我們不宣稱全部資料「絕不出內網」。資料庫本身毋須作為公網服務開放。

如何核對官方交付套件？

正式版本可提供 SHA-256 校驗值，以檢查檔案完整性。雜湊校驗不等同數碼簽署、安全認證或無漏洞證明；映像簽署及漏洞掃描應另行提供發佈紀錄。

這是線上薪資 SaaS 嗎？

採用企業自建服務端與官方 iOS 客戶端的模式。企業負責服務端與資料，員工裝置直接連接企業 HTTPS 位址。此產品介紹網站不承載企業工資資料庫。

會自動計算 MPF 或申報 IR56 嗎？

目前負責匯入、審核、發佈與查閱糧單，不代替 MPF、假期薪酬、薪俸稅核算或 IR56 申報。糧單數據以企業核定結果為準。

一般員工也要建立後台帳戶及 MFA 嗎？

毋須。員工檔案與後台操作帳戶分開，由授權 HR 核實身份及綁定手機。後台人員使用密碼與 MFA，員工在 App 內使用系統認證解鎖。

可以於內網使用 IP 位址存取嗎？

正式環境必須使用 HTTPS。管理員可啟用內網 IP HTTPS，自動建立自簽憑證；內網電腦及手機須安裝並信任憑證。員工 iOS 配對繼續使用企業設定的公開 HTTPS 位址。

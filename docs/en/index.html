A payslip and an MPF pay-record have distinct requirements.

MPFA requires employers to issue a monthly pay-record within seven working days after contributions are remitted to eMPF. It includes relevant income, each party’s mandatory and voluntary contributions, and the contribution date. Importing these details does not replace checking completeness or issuing the record on time.

Open the deployment checklist
  1. Choose your own machine or a server you manage. Prepare Docker, persistent storage and a backup location.
  2. Configure an employee-accessible HTTPS address and trusted proxy. Direct internal HTTP login is blocked in production.
  3. Use the released image, Compose configuration and deployment documentation; complete core source is not required. Preserve data volumes, accounts and MFA when upgrading.
  4. Have a system administrator configure the organisation and admin roles. Authorised HR staff create employee records and verify identity before pairing.
  5. For internal IP HTTPS, an administrator can enable a self-signed certificate in the backend. Distribute certificate trust to internal devices.

The official image registry and public deployment materials await release. This page describes the delivery model, not an available registry command. Community Edition does not imply an open-source licence.

04 / GOOD TO KNOW

Before you begin,
a few useful answers.

Does Community Edition mean open source?

No. It describes a free self-hosted delivery model, not a promise to release all core source code. Public deployment materials, Excel field examples and documentation follow their published licences and release scope.

Does all data stay inside the intranet?

The database resides on infrastructure you manage. When an authorised employee connects remotely, relevant payslip data travels to their device over HTTPS. We therefore do not claim that all data never leaves the intranet. The database itself does not need a public service endpoint.

How can we check an official release?

SHA-256 checksums can check file integrity. A checksum is not a digital signature, security certification or proof of zero vulnerabilities. Image signatures and vulnerability scans need their own release evidence.

Is this a shared payroll SaaS?

No. Your organisation runs the server and controls the data. Employee devices connect directly to your HTTPS address through the official iOS app. This product website does not host your payroll database.

Does it calculate MPF or file IR56 returns?

The current service imports, reviews, publishes and displays payslips. It does not replace MPF or statutory-pay calculations, salaries tax calculations or IR56 filing. Payroll figures come from your organisation’s approved records.

Do employees need admin accounts and MFA?

No. Employee records are separate from admin accounts. Authorised HR staff verify identity and pair the phone. Admins use passwords and MFA; employees unlock the app with system authentication.

Can we use an internal IP address?

Production access requires HTTPS. Administrators can enable internal IP HTTPS and generate a self-signed certificate. Internal computers and phones must install and trust it. Employee iOS pairing continues to use the configured public HTTPS address.
